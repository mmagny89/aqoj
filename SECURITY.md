# Sécurité

## Versions suivies

Seule la dernière version publiée (branche `main`) reçoit des correctifs de
sécurité.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.** Utilisez le signalement privé de GitHub :
onglet *Security* → *Report a vulnerability*.

Décrivez la faille, comment la reproduire et son impact. Vous recevrez une
réponse sous 7 jours. Le correctif est publié avant toute divulgation, et la
personne qui a signalé la faille est créditée si elle le souhaite.

## Périmètre

« À quoi on joue » est l'application ; les données de BoardGameGeek et les
services d'hébergement sont hors périmètre.
